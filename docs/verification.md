# Проверка версии 1.0

Проверено 15 октября 2026 года на macOS Apple Silicon, Node.js 24, Chromium.

## Автоматические проверки

- TypeScript и production-сборка Vite проходят.
- Форматирование исходников проходит Prettier.
- 14 тестов проходят: структура проекта, ограничения рендера, отсутствие повторных ID, непрерывность таймингов и перестановки, все четыре шаблона, SRT и сценарий, восстановление позиции при отмене структурных изменений.

## Проверка в браузере

- Заголовок обновляется одновременно в инспекторе, кадре и миниатюре.
- Палитра меняет фон композиции; отмена возвращает прежнюю.
- Дублирование и удаление меняют число сцен.
- После удаления последней сцены выбранная сцена и предпросмотр совпадают.
- Воспроизведение обновляет время и переключает состояние кнопки.
- Шаблон Remotion заменяет тексты и пример кода проекта.
- Форматы 1920×1080, 1080×1920 и 1080×1080 отображаются в студии; квадратный использует вертикальную компоновку.
- На экране 390×844 нет горизонтального переполнения страницы.
- Из интерфейса запущен и завершён Full HD экспорт; ссылка на файл отвечает HTTP 200.

## Проверка сервера и видео

- `/api/health` отвечает 200.
- Некорректный проект получает 400.
- Посторонний Origin получает 403.
- Рендер короткого двухсекундного проекта через HTTP API завершается статусом `done`.
- Полный демонстрационный урок действительно отрендерен в MP4.
- Метаданные проверены ffprobe: H.264, 1920×1080, 30 fps, примерно 36 секунд; небольшое округление длительности контейнера связано с аудиопотоком AAC.
- Кадр со сценой кода извлечён из MP4 и проверен визуально.

## Что эти проверки не покрывают

Не выполнялся автоматический полный E2E-набор для всех перестановок и форматов. Не проверялись все версии Firefox/Safari и реальные мобильные устройства. Нет тестов многопользовательской работы: текущая архитектура предназначена для локального автора.

## Минималистичный интерфейс и темы

Убраны декоративные иллюстрации, градиенты, сиреневые акценты, цветные таймлайн-клипы и повторяющиеся слоганы. Видеосцены используют код, результат его отображения и схемы. Нейтральные значения палитр сохраняют прежние идентификаторы JSON для совместимости.

Проверено в Chromium: системная тема по умолчанию, автоматический переход при смене prefers-color-scheme, ручная светлая тема при тёмной системной и её сохранение после перезагрузки. Тема редактора не меняет Project.theme. Новые тесты проверяют разрешение темы и сохранность пользовательских текстов при обновлении исходного демо. Проверка TypeScript с noUnusedLocals также проходит.
