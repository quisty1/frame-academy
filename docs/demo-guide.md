# Демонстрация работодателю за 3 минуты

## 0:00–0:30 — задача продукта

«Frame Academy — инструмент для эксперта, который делает видеоуроки. Здесь можно собрать структуру объяснения, показать код, подготовить сценарий и получить видео. Я выбрал образовательный сценарий, чтобы связать React и Remotion с реальной работой автора курса».

Покажите студию и запустите первые сцены.

## 0:30–1:15 — React и управление состоянием

Измените заголовок справа — он сразу изменится в видео и миниатюре. Выберите палитру. Дублируйте сцену, измените её длительность, переставьте на таймлайне. Покажите отмену.

Объясните разделение: модель проекта, состояние редактора, состояние плеера. Упомяните Zod-проверку импорта и автосохранение.

## 1:15–2:00 — Remotion и объяснение сложного

Перейдите к сцене с кодом. Покажите редактирование примера и покадровое воспроизведение стрелками. Затем откройте вкладку «Сценарий».

«Движение зависит от номера кадра. Один React-компонент используется и в предпросмотре, и в MP4. В примере обучения сначала идёт идея, затем код, затем маленькое упражнение».

Откройте шаблон «Видео из кода», чтобы показать объяснение самого Remotion. Применение шаблона можно отменить.

## 2:00–2:45 — настоящий экспорт

Нажмите «Экспорт видео» → «Экспортировать видео». Покажите прогресс. Пока видео создаётся, откройте пространство автора и выгрузите сценарий или SRT. Если рендер на компьютере занимает больше времени, покажите заранее подготовленный `frame-academy-demo.mp4`.

## 2:45–3:00 — завершение

«Исходники разделены по ответственности, модель и тайминги покрыты тестами. Этот проект показывает мой подход к интерфейсам и образовательным инструментам. Следующим шагом я бы добавил голосовую дорожку и библиотеку проектов».

## Текст для сообщения

Здравствуйте! Подготовил проект Frame Academy — студию создания обучающих видео на React, TypeScript и Remotion. В ней есть редактор сцен, таймлайн, живой предпросмотр, готовые уроки по React и Remotion, сценарий преподавателя и экспорт MP4. Прикладываю исходники с инструкцией запуска и короткое демонстрационное видео. Буду рад показать архитектуру и обсудить создание уроков для вашей школы.

При необходимости замените формулировки так, чтобы они точно отражали ваш личный вклад и опыт. Репозиторий сам по себе не подтверждает длительность опыта и навыки публичного выступления; подготовьте живое объяснение выбранной темы своими словами.
