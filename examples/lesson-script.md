## 3. Функция, которая возвращает JSX

**Тайминг:** 00:00:14 · 9 сек

**В кадре:** Функция возвращает разметку. React превращает её в интерфейс.

### Слова преподавателя

Это обычная JavaScript-функция. Название начинается с большой буквы. Синтаксис внутри return называется JSX. Обратите внимание на фигурные скобки: так мы вставляем значение переменной.

### Пример кода

```jsx
function Welcome({ name }) {
  return (
    <div className="card">
      <h1>Привет, {name}!</h1>
      <p>Рад тебя видеть.</p>
    </div>
  );
}
```
